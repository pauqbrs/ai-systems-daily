### `slug-del-proyecto`

**Qué es:** una o dos frases. Qué hace el sistema y para quién.

**En qué fase está:** exploración / prototipo / en producción con N usuarios.
Importa porque cambia qué material sirve: en exploración interesan las
arquitecturas, en producción interesan el coste, la latencia y los modos de fallo.

**Stack relevante:** modelos, framework de orquestación, base de datos, dónde corre.

**Qué material le sirve:**
- Lo que resuelve un problema que ya tienes abierto (di cuál).
- Lo que invalida una decisión que ya tomaste.
- Lo que baja coste o latencia de un camino que ya ejecutas.

**Qué material NO le sirve:** para que las piezas no aterricen aquí por defecto.

**Preguntas abiertas:** las dudas concretas que tienes ahora mismo. Esto es oro
para el aterrizaje: si una fuente responde una de estas, la pieza casi se escribe sola.
